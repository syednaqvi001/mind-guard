# 🛡️ Mind-Guard Clinical Portal

**Mind-Guard** is a premier, full-stack AI-powered mental health platform designed to bridge the gap between patient reflections and clinical intervention. Leveraging a sophisticated "Triple-LLM" pipeline, it provides real-time distress detection, risk scoring, and therapist-driven resolution workflows.

---

## 🌟 Premium Features

- **🧠 Triple-LLM Orchestration**: Automated sentiment analysis, distress detection, and insight generation using Hugging Face APIs.
- **🏥 Clinical Triage Dashboard**: A modern, glassmorphic therapist workspace with collapsible sidebar architecture for focused patient review.
- **🔒 Enterprise-Grade Security**: AES-256 journal encryption, decoupled environment configurations (.env), and JWT-based authentication.
- **🤝 Integrated Care Loop**: Accurate therapist attribution for alert resolutions, providing patients with immediate professional feedback.
- **📊 Real-time Monitoring**: Asynchronous AI analysis that flags critical signals (SOS) instantly for therapist intervention.

## 🏗️ Technical Stack

- **Backend**: Spring Boot 3.3, Java 21, PostgreSQL, Hibernate.
- **Frontend**: Angular 18, TypeScript, Custom SCSS (Glassmorphism).
- **AI Integration**: Hugging Face Inference API (DistilBERT, BART).
- **Security**: JWT, AES-256, Dotenv, CORS Hardening.
